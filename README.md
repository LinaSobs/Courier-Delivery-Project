# Digital Courier Services System

📌 Project Overview
APDJ Phase 3 Project is a Windows Forms Application developed using C# and .NET Framework.
The project simulates a Digital Courier Services System that allows users to log into the application and access courier management features through a desktop-based interface.

The application includes a user authentication system with a graphical user interface and integrates a SQL Server Local Database for handling user-related data.

---

## 🎯 What the Project Does

The system allows users to:

* Log into the application using a username and password
* Validate user credentials before granting access
* Display error messages when incorrect login details are entered
* Clear login input fields after failed login attempts
* Navigate between different application forms
* Exit the application safely
* Hide and show password characters for improved usability

## ▶️ Installation and Setup Instructions

### Requirements

Before running the project, make sure you have the following installed:

* Visual Studio
* .NET Framework
* SQL Server LocalDB

### Steps to Run the Application

1. Download or extract the project files.
2. Open the solution file in Visual Studio.
3. Restore NuGet packages if prompted.
4. Ensure SQL Server LocalDB is installed and running.
5. Open the project database connection settings if needed.
6. Build the solution using:

```bash
Ctrl + Shift + B
```

7. Run the application by pressing:

```bash
F5
```

8. The login form will appear and the application will be ready to use.
